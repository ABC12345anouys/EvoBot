# 04 · 失败分类与恢复

> 对应代码：`darwin/physics/`（观测、判别、恢复建议、参数推导、状态估计）
>
> 上游：技能执行时产生观测（`darwin/skills/primitives/ik_servo.py`、`darwin/agents/libero_skills.py`）。
> 下游：Agent 的重规划与重试（`darwin/agents/libero_planner.py` 的重规划提示、`darwin/agents/libero_runner.py` 的重试循环）。
>
> 项目定位不变：**Agent + 可复用技能**。Agent 负责选技能、按结果改参数或改做法；技能负责把一次动作执行完，并在失败时说清楚**为什么失败**。

## 1. 为什么失败要分类，而不是返回"成功 / 失败"

技能执行完，只返回一个布尔值，上层能做的只有"再试一次"。但同样一句"没成功"，背后的物理原因可能完全不同：

- 机械臂已经够到极限，再推也推不动 → 重试无用；
- 抓取点正好压在障碍上 → 该换抓取位置；
- 下降速度太快、时间不够 → 多给时间就能成；
- 夹爪和物体之间打滑 → 该加大夹持力、放慢动作；
- 物体被沿口弹飞 → 该改放置点，而不是加力。

如果只给布尔值，上层只能盲试，把宝贵的重试次数烧在错误的方向上。因此技能失败时返回的是一个**失败原因分类**（代码里叫 mechanism，即"失败机制"），上层据此决定：换参数、换抓取位置、还是换一种做法。

分类带来的三种处理方式：

| 失败性质 | 能靠改参数解决吗 | 上层的动作 |
|---|---|---|
| 动态/控制类（太慢、太急、打滑） | 能 | 调参数后重试 |
| 几何类（被挡、够不到、被弹飞） | 不能 | 换抓取位置、改放置点或路径 |
| 任务本身不适合抓取 | 不能 | 换做法（例如从抓取改为推动） |

## 2. 证据：分类的原料

分类不是靠猜，而是靠执行期间记录下来的物理信号。`darwin/physics/observables.py` 定义了证据对象 `Evidence` 和采样器 `Collector`：

- **每次技能执行都在采样**：沿 z 轴的位置、水平位置 xy、指尖与物体之间的接触力、与障碍的最小间隙、碰撞对。
- **成功和失败都采**：一次干净的成功下降同样测到了接触高度和可达短缩，这些数据不会浪费。
- **接触力按稀疏节奏采**：默认每 10 步采一次，并在判定点（例如停滞窗口）和结束时补采一次。
- **派生量**：`z_rate_median()` 给出窗口内的中位下降速率（抗单步噪声），`f_at_end` 给出结束时的接触力。判别只用窗口值和终值。

两个最常用的判读量：

- `F_FREE_N = 0.5 N`：低于这个接触力，认为指尖在自由空间、没有真正接触；
- `RATE_EPS = 0.2 mm/步`：低于这个下降速率，认为已经停住。

## 3. 失败分类清单

分类枚举定义在 `darwin/physics/discriminators.py` 的 `Mechanism`，共 10 项。下表列出每一类的含义与判别时读哪些信号。

| 分类 | 含义（白话） | 判别依据 |
|---|---|---|
| `reach_limit` | 机械臂已经到可达极限，停在目标略上方，属于"够到极限"而非故障 | 末端接触力接近 0（自由空间），下降速率为 0，停点距目标上方不超过 35 mm |
| `contact_blocked` | 指尖真的碰到了东西，被实体挡住下不去 | 末端接触力 ≥ 0.5 N，且停点距目标上方在 35 mm 以内 |
| `budget_short` | 一直在缓慢前进，只是时间不够 | 接触力接近 0，但下降速率高于 0.2 mm/步（在匀速慢速推进） |
| `ik_unreachable` | 目标点够不到，或下降途中被障碍带偏 | 三种入口：无接触且完全停住但停点不在目标上方 35 mm 内；有接触且停点高于 35 mm；失败原因里含 xy 漂移 |
| `no_grip_air` | 夹空：全程没接触，或物体没有跟着抬起来 | 全程最大接触力都低于 0.5 N；或"物体是否跟随"判为否 |
| `friction_slip` | 打滑：指和物之间摩擦力不够，物体慢慢滑走 | 曾接触但力不足，滑移距离小于 50 mm，或滑移方向未知时保守归入此类 |
| `geometry_squeeze` | 被几何挤飞：物体被沿口弹开 | 滑移距离 ≥ 50 mm（被弹出）；或放置超时且最小间隙 ≥ 5 mm |
| `clearance_violation` | 间隙不够，下降或放置时蹭到障碍 | 失败原因含碰撞；或放置超时且最小间隙 < 5 mm |
| `support_overflow` | 物体重心投影超出支撑面，放上去会倒 | **枚举与恢复建议中已声明，但当前没有判别分支会产出它**（见 §6） |
| `unknown` | 以上关键词都没命中 | 分发时的备用分类 |

`friction_slip` 与 `geometry_squeeze` 必须分开：两者都表现为"物体滑走"，但**摩擦滑走**（沿爪缓慢下滑，位移通常不到 1 cm）要改物理参数，**被沿口弹出**（位移通常超过 5 cm）要改几何，量级差足以区分。若不做这一步区分，上层只会一刀切地反复试同一套参数。

## 4. 从失败原因到分类

技能的失败原因是一段文本（例如 `ik_descend_stalled`、`place_timeout`、`..._slipped`）。`discriminate(reason, evidence, **ctx)` 按关键词把原因路由到对应的判别函数：

| 原因关键词 | 走的判别 |
|---|---|
| `xy_drift` | 直接判 `ik_unreachable` |
| `stalled` / `stall` | `classify_stall`（停滞的三分：可达极限 / 被挡 / 时间不够） |
| `no_grip` / `grip_fail` | `classify_no_grip`（夹空 vs 打滑） |
| `slipped` / `slip` | `classify_slip`（打滑 vs 被弹出） |
| `timeout` | `classify_place_timeout`（物体没运到 / 间隙不足 / 被挤飞） |
| `collision` | 直接判 `clearance_violation` |
| 其余 | `unknown` |

判别需要的少量上下文由调用方现算后传入，例如滑移方向、物体是否跟到目标附近（水平距离 < 50 mm 视为跟到）、目标高度等。

技能层自己产出的原因字符串（`darwin/agents/libero_skills.py` 里的 `_fail`：`ik_unreachable` / `no_candidate` / `perception_fail` / `action_fail` / `timeout` / `slow_budget` / `contact_blocked` 等）与上面的分类名**只有部分重合**，重合的部分直接使用，没对上的会被路由为 `unknown`。分类负责回答"物理上到底哪里不行"，技能原因字符串负责日志和反思，两者是互补关系。

## 5. 恢复手段

`darwin/physics/cuts.py` 的 `cut_for(mechanism, evidence, ...)` 把分类翻译成两类恢复建议：`theta_cut`（收窄未知物理量的取值范围）和 `directive`（几何 / 路径上的直接指令）。

### 5.1 换参数

参数类恢复只对动态/控制类失败有效：

- **时间不够**（`budget_short`）：按"距离 ÷ 实测速率 × 1.3"重新推算所需步数，写入 `timeout_need`（置信度 0.9）；重试时按第几次把时间乘 2 / 3 / 4.5 倍。
- **被打滑**（`friction_slip`）：收紧摩擦系数上界，条件为 `μ ≤ m·g / F`（m 是物体质量，F 是实测夹持力，置信度 0.85）；放置阶段同时提高增益、降低末速。
- **被挡**（`contact_blocked`）：更软更慢，增益和限速都往下降。
- **够不到但收敛慢**（`ik_unreachable`）：提高增益、放宽时间。
- **已经到极限**（`reach_limit`）：不给参数方向（重试没有意义），进入 §5.4 的接受判定。

参数的具体倍数取自 `darwin/policies/retry.py`，按重试次数递进；同一原因不会重复烧同一个方向。

### 5.2 换抓取位置

几何类失败改参数无效，必须换位置：

- `no_grip_air`（夹空）：换候选抓取点，或调整 straddle 偏置（让两指分跨容器沿口）。偏置比例默认取物体半宽的 0.70，也可由点云净空直接推导。
- `contact_blocked`（被挡）：把抓取点移出障碍或沿口外扩的范围，或换 straddle 方向。
- `ik_unreachable`（够不到）：改路径点、抬高悬停高度、改接近角，绕开障碍。

候选层面用"候选黑名单"落实：机制落在 `no_grip_air` / `geometry_squeeze` / `contact_blocked` / `ik_unreachable` 且失败发生在抓取阶段时，该抓取点的水平坐标被登记；同一位置失败满 2 次才真正拉黑下次不再用（单次失败的标签有噪声，双次才触发可避免误杀）。只有抓取阶段的失败才拉黑抓取点，放置阶段的失败不牵连抓取点。

### 5.3 换做法

有些任务本就不适合抓取，此时换位置也没用，应换一种实现方式。`darwin/physics/derives.py` 的 `pushable_by_thickness` 判断物体是否过薄（厚度 < 20 mm 时上夹爪难以形成稳定夹持）而应改为推：`push_z` 把指尖对齐到物体厚度中部，`push_start_xy` 把推动起点放在物体背离目标的一侧，避免直线路径横穿物体；技能层对应 `libero_skills.py` 的 `push_to`。此外，`ik_unreachable` 也会视目标点是否落在可达范围内，决定是直接换抓取点还是改接近路径。

### 5.4 重试与接受

- **重试**：改完参数或位置后，用改动后的配置重新执行同一子目标。
- **接受**：`reach_limit` 是"已到极限"的自然结果。若停在目标上方 35 mm 带内、水平方向已经对准、又没有接触力，这一步被判为到位并接受（接触软停带内的停滞同样接受），不会当作失败。
- **向上传播**：`unknown` 或参数已无调整空间时，把失败交给上层重规划（`darwin/agents/libero_planner.py` 的 `replan_hint`：抓取落空或够不到就换抓取候选，其余分类用新观测重跑同一子目标）。

### 5.5 恢复建议一览

| 分类 | 换参数 | 换位置 / 换做法 |
|---|---|---|
| `reach_limit` | 无（接受判定处理） | — |
| `contact_blocked` | 增益、限速下调 | 抓取点移出障碍；换 straddle 方向 |
| `budget_short` | 时间按 ×2/×3/×4.5 递进 | — |
| `ik_unreachable` | 增益上调、时间放宽 | 换路径点；抬高悬停；改接近角 |
| `no_grip_air` | — | 换候选抓取点；调 straddle 偏置 |
| `friction_slip` | 放置时增益上调、末速下调；抓持时压得更深 | — |
| `geometry_squeeze` | 参数无效，保持原配置 | 放置点向支撑面内收；提前释放 |
| `clearance_violation` | — | 提高间隙余量；绕障路径 |
| `support_overflow` | — | 放置点向支撑面内收 |
| `unknown` | 通用参数阶梯 | 交由上层重规划 |

## 6. 各模块职责

| 文件 | 职责 | 关键接口 |
|---|---|---|
| `darwin/physics/observables.py` | **观测与证据**：执行期逐样本采样，成功失败都留证据 | `Collector`、`Evidence`、`F_FREE_N`、`RATE_EPS` |
| `darwin/physics/discriminators.py` | **判别**：从原因文本和证据判定失败分类，判别函数是纯函数 | `Mechanism`、`discriminate`、`classify_stall` / `classify_no_grip` / `classify_slip` / `classify_place_timeout` |
| `darwin/physics/cuts.py` | **恢复建议**：分类 + 证据 → 参数不等式或几何指令 | `cut_for`、`Cut` |
| `darwin/physics/constraints.py` | **成功后的校核**：在 lift / carry 成功的那一刻做力封闭检查，提前预警夹持不稳；另含摩擦锥、支撑面、可达、夹持力、装配间隙、接近走廊等几何/物理检查，供运行时监视使用 | `force_closure_lite`、`reach_feasible`、`grip_force_need_met`、`insertion_clearance_ok`、`approach_corridor_ok`、`active_set` |
| `darwin/physics/derives.py` | **参数推导**：参数 = 场景特征的函数，而不是手调常数（步数预算、接触软停带、抓取几何、推动几何、摩擦锥到末速的换算）| `descend_timeout`、`contact_stop_band`、`straddle_offset`、`pushable_by_thickness`、`place_vcap_from_mu`、`grip_force_need` |
| `darwin/physics/posterior.py` | **状态估计**：把未知物理量（摩擦系数、可达短缩、步数预算）表示为一个取值范围，每条恢复建议收窄一次；按环境持久化，跨尝试复用 | `ThetaPosterior.cut / domain / measure / load` |
| `darwin/physics/probes.py` | **主动测量**：用一次低速小步实验直接测出物理量（接触高度、可达短缩、摩擦系数），比反复试参数更快 | `contact_probe`、`reach_probe`、`friction_probe` |
| `darwin/physics/articulation.py` | **关节类物体**：用一份声明同时描述柜门、抽屉、翻盖、旋钮（转轴 / 平移轴、轴点、限位），并检查作用点是否还在正确轨迹上、是否在限位内、施力方向是否对准。适用范围是已知轴、带限位的单链刚体；多链折叠门、柔性门封、会变形的物体不在承诺范围内 | `JointDecl`、`on_manifold_track`、`within_limits`、`aligned_wrench`、`mechanism_of_violation` |

关于状态估计的两条更新规则值得说明：只有新证据的置信度高于已有记录时才收窄范围；如果新证据与已有范围矛盾，则保留较宽的范围并把置信度减半，避免一次误判把范围切错方向。

`support_overflow` 目前是一个**已声明但未启用**的分类：它在枚举和恢复建议表里存在，但判别阶段没有任何分支会产出它。放置失稳目前主要通过 `geometry_squeeze` 和 `clearance_violation` 表达。

## 7. 关键阈值表

| 名称 | 取值 | 含义 |
|---|---|---|
| 自由空间力阈值 | 0.5 N | 低于此值视为指尖未接触物体 |
| 停滞速率地板 | 0.2 mm/步 | 低于此值视为停住 |
| 可达停滞带 | 35 mm | 无力且停在此带内，判为"够到极限" |
| 弹射判距 | 50 mm | 滑移超过此距离判为被弹出 |
| 放置间隙阈值 | 5 mm | 小于此值判为间隙不足 |
| 物体跟随判距 | 50 mm | 物到目标的水平距离小于此值视为运到 |
| 下降水平容差 | 15 mm | 水平偏差超过此值不算到位 |
| 接触软停带（容器 / 实心） | 15 mm / 50 mm | 进入目标上方此带内的停滞可接受 |
| 步数预算裕度 | 1.3 | 按距离 ÷ 实测速率再乘 1.3 |
| 状态估计初始范围 | 摩擦系数 0.05–2.0；可达短缩 0–0.15 m；步数预算 60–2000 | 未知物理量的初始取值区间 |
| 名义摩擦系数 / 力封闭安全系数 | 0.5 / 1.5 | 夹持力需满足 1.5·m·g / μ |
| 装配间隙容差 | 3 mm | 小于此值直插会失败 |
| 接近走廊余量 / 指半径 | 4 mm / 8 mm | 路径与障碍的最小余量 / 手指包络半径 |
| 推策略厚度上限 | 20 mm | 薄于此厚度优先改用推动 |
| straddle 偏置比例 | 0.70 | 偏置 = 0.70 × 物体半宽 |
| 候选拉黑阈值 / 匹配半径 | 2 次 / 20 mm | 同一抓取点失败满 2 次才拉黑 |
| 关节轨迹容差 / 限位余量 | 15 mm / 20 mm | 判断作用点脱离轨迹、是否接近限位 |

## 8. 失败 → 分类 → 恢复 流程

```
技能执行：执行期持续采样（位置 / 接触力 / 间隙 / 碰撞）
        │
        ▼
技能返回：成功 → constraints 校核（力封闭 / 夹持力 / 间隙）并预警
        │
        ▼ 失败（原因文本 + 证据）
   按原因关键词分发（discriminate）
        │
        ▼
   失败分类（Mechanism，10 类）
        │
   ┌────┴──────────────────────────┐
   ▼                               ▼
动态 / 控制类                    几何类 / 任务类
（够不够、快不快、滑不滑）        （挡没挡、够没够、能不能抓）
   │                               │
   ▼                               ▼
参数不等式（theta_cut）          几何 / 路径指令（directive）
   ├─ 收窄物理量范围（posterior）  ├─ 换抓取位置（候选黑名单）
   ├─ 换执行参数（retry）          ├─ 改放置点 / 路径点
   └─ 调整任务级配置（reflection） └─ 换做法（例如改用推动）
                  └────────┬────────┘
                           ▼
                  用新配置重试同一子目标 → 仍失败则交上层重规划 / 换候选
```
