## 整体流程

```
任务定义文件
   │  结构化解析（离线做一次：模型读取任务定义，决定执行顺序，结果写成 YAML 存进仓库）
   ▼
有序子目标 ──► 技能序列 ──► 环境适配层 ──► LIBERO / robosuite
   ▲               │
   │               └── 失败原因分类 ──► 换参数 / 换抓取位置 / 换做法
   └── 重试

感知（01）为技能提供物体位姿与抓取候选；逆运动学与伺服（06）为技能提供末端动作。
```

## 阅读建议

- **想先看整体**：01 → 02 → 03
- **想改技能**：03（技能约定）→ 04（失败处理）
- **想接入新环境或新机器人**：05 → 06
- **想知道任务定义文件长什么样**：02 里有完整示例与重新生成的命令
